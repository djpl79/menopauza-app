# Menopauza App

Aplikacja do śledzenia objawów menopauzy, edukacji i wsparcia dla kobiet.

## 🎯 Funkcje

- 📊 Śledzenie objawów (gorące uderzenia, zmęczenie, nastrój, sen)
- 📚 Baza wiedzy po polsku o menopauzie
- 💬 Forum dyskusji i wsparcia społeczności
- 📈 Wykresy postępu i statystyki
- 🔔 Przypomnienia i personalizowane porady
- 👤 Profile użytkowników z historią

## 🛠️ Stack Techniczny

- **Frontend**: React 18+
- **Backend**: Node.js + Express
- **Baza danych**: PostgreSQL
- **Autentykacja**: JWT
- **Styling**: Tailwind CSS

## 📁 Struktura Projektu

```
menopauza-app/
├── backend/              # Node.js + Express
├── frontend/             # React app
├── docs/                 # Dokumentacja
└── docker-compose.yml    # Docker setup
```

## 🚀 Instalacja

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm start
```

### PostgreSQL
```bash
docker-compose up -d
```
